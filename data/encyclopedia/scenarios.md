# 百科库场景词表（FAQ 通用情境）

> 用途：16 人格 FAQ 条目的 `scenario` 字段必须命中本表中的某个 key（slug），
> 用于 AI 对话时按场景路由到对应人格的同情境条目做 RAG 检索。
> 维护：场景词表与 PRD §3.4「FAQ 缓存」对齐，新增高频场景需同步更新本表并跑 `scripts/check_encyclopedia.py` 校验。

| slug | 中文名 | 说明 |
|---|---|---|
| public-speaking | 公开演讲 | 会议汇报、当众发言、上台做 presentation 前的紧张与准备 |
| conflict | 人际冲突 | 朋友/同事/家人之间产生分歧甚至争吵时的处理 |
| deadline | 截止日期 | 项目、作业、报告临近 DDL，时间不够用的压力应对 |
| breakup | 分手失恋 | 亲密关系结束后的情绪波动和自我调整 |
| teamwork | 团队协作 | 多人共同完成任务时的沟通、分工与冲突协调 |
| criticism | 被批评 | 上级/同事/朋友提出否定或质疑时的心理反应与应对 |
| alone-weekend | 独处周末 | 没有安排、一个人度过周末或长假的方式选择 |
| new-job | 入职新岗 | 换工作、入职第一天、面对陌生团队和环境的适应 |
| decision | 重大抉择 | 多条路难分优劣、人生方向选择时的思考方式 |
| social-drain | 社交疲惫 | 长时间与人打交道后精力被抽空、想独处恢复的状态 |
| exam | 备考突击 | 考试、面试、资格认证前临时抱佛脚的高压复习 |
| family-pressure | 家庭压力 | 父母/亲属催婚、催生、催考编、价值观念冲突时的张力 |
| creative-block | 创作瓶颈 | 写作、设计、策划、写代码等需要创造力输出时卡壳 |
| money-issue | 钱的问题 | 突然缺钱、被借债、月光、账单压力等经济相关焦虑 |
| self-doubt | 自我怀疑 | 长期怀疑自己价值、意义感缺失、是否选错了方向 |
| networking | 主动社交 | 为了业务/求职主动认识陌生人、破冰、加好友的场合 |
| caregiving | 照顾他人 | 照顾生病的家人、年幼的孩子、身体虚弱者的长期消耗 |
| relocation | 搬家换城 | 离开熟悉环境到陌生城市工作生活的过渡期 |
| learning-new-skill | 学习新技能 | 入门一门新学科/新技术，从零开始的迷茫与节奏选择 |
| leading-team | 带团队 | 作为 leader 安排任务、激励下属、处理团队内分歧 |

合计 20 条场景，覆盖工作、生活、情感、学习四大类。所有 16 人格 × 10 条 FAQ 共 160 条
均从这 20 个场景中各人格独立挑选，使 AI 对话时同一情境下能横向对比 16 人格的差异化反应。
