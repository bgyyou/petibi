# 工单：计分引擎（src/scoring/）

> 里程碑：M2 | 执行：子 agent（M3） | 终审：主 agent
> 数据契约：docs/tech/M2-数据契约.md §1（题库 schema）+ §4（引擎接口与计分规则）
> 对应红线：R5（确定性 + 16 型可达遍历）、R9（注释）

## 任务

按契约 §4 实现 TypeScript 纯函数计分引擎：

- 文件：`src/scoring/score.ts`（实现）+ `src/scoring/types.ts`（类型）
- 严格遵守契约的接口签名、计分规则、平局取第一极规则；无任何 IO/随机/时间依赖
- 测试：`src/scoring/score.test.ts`（用项目现有测试框架；若项目尚无测试框架，选 vitest 并配好，注意 electron-vite 项目兼容性）
- 测试用 fixture：构造内联的迷你题库（每维 2 题即可），不依赖 data/questions/（题库由另一并行任务生产）

## 自验清单（附实际命令输出）

1. `npx vitest run`（或对应命令）全过，输出贴进报告
2. 必含用例：确定性（同 answers 调 100 次全等）；平局取第一极；direction 反向题计分正确；16 型 + 2 细分可达性遍历（构造极化答案向量）；非法输入（缺题/越界评分）抛错
3. `python scripts/check_comments.py` 通过（R9）

交付报告：`docs/tech/M2-计分引擎-交付报告.md`（命令输出 + 设计取舍说明 + 遗留问题）。不 commit，不动其他目录（package.json 加 vitest 依赖允许）。
