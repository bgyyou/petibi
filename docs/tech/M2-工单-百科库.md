# 工单：百科知识库生产（data/encyclopedia/）

> 里程碑：M2/M3 核心数据资产 | 执行：子 agent（M3） | 终审：主 agent
> 数据契约：docs/tech/M2-数据契约.md §2（先读，严格按 schema）
> 对应：PRD §3.6（百科是 AI 对话的 RAG 数据底座）

## 任务

按契约 §2 产出 16 人格百科库：

1. 先建 `data/encyclopedia/scenarios.md`：约 20 个高频生活场景词表（public-speaking / conflict / deadline / breakup / teamwork / criticism / alone-weekend / new-job / decision / social-drain …），每个场景一句中文说明
2. 每人格一个文件 `data/encyclopedia/<人格小写>.json`，25 条 entries（trait 4 / cognitive 2 / strength 3 / weakness 3 / career 2 / relationship 1 / faq 10），faq 的 scenario 必须来自场景词表
3. 内容基于公开 MBTI 理论共识撰写，中文，口语化但专业；faq 条目用"作为 X，通常会……"视角写（这就是 AI 回答的素材风格）；不复制任何版权文本
4. `index.json`：16 人格索引（人格、动物、族、条目数）

## 自验清单（附实际命令输出）

1. 写 `scripts/check_encyclopedia.py` 并运行通过：16 文件齐全；每文件 25 条；category 分布正确；id 唯一且含人格前缀；faq 的 scenario 全部在词表内；content 字数达标（trait 80-150 字 / faq 120-200 字）
2. 抽查 3 个人格的 faq 内容人格化程度（回答口吻确实是该人格而非万能鸡汤）

交付报告：`docs/tech/M2-百科库-交付报告.md`（命令输出 + 1 个完整人格示例 + 遗留问题）。中文注释（R9）。不 commit，不动其他目录。
