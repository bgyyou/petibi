## 2. 修复脚本 `scripts/fix_portraits_v6.py`

### 2.1 设计

两张黄色染色问题（estp 猴子 / isfp 卡皮巴拉）共用同一函数 `fix_yellow_in_head(code)`：

- **黄色→棕色系映射**（保持明度梯度）：

  | explorer 服装色 | RGB | → 中性毛色 | RGB |
  | --- | --- | --- | --- |
  | main #E4C728 | (228,199,40) | → 棕 #8B5E3C | (139,94,60) |
  | shadow #7D6D16 | (125,109,22) | → 深棕 #5C4033 | (92,64,51) |
  | light #EBD55E | (235,213,94) | → 浅棕 #C49A6C | (196,154,108) |
  | highlight #F0E089 | (240,224,137) | → 浅棕 #C49A6C | (196,154,108) |

- **头部阈值 y < 200**：画布顶部 1/3 多一点。角色全身像头部通常在此区间，躯干衣服区域在 y ≥ 230 中下部中心区。覆盖 owner 工单原话"脸/手"的范围。
- 不动衣服（y ≥ 200 的黄色像素全部保留）。

infj 白羽描边问题用 `fix_white_feather_outline(code)`：

- **两遍扫描定位外缘白羽**：
  1. 8-邻域含 #FFFFFF 的白羽/奶油像素 → #2B2320 描边（最外圈）
  2. 4-邻域含 #FFFFFF 但 8-邻域不含 → #9A9A9A 浅灰过渡（次外圈，但本次修复结果此圈为空 → 像素风已足够干净，不需要浅灰过渡）
- **描边不重入**：已经标为描边的像素的 4-邻域白羽不再追加描边色，避免黑边变粗。
