# M2 题库交付报告

## 交付内容

- 题库：`data/questions/questions.json`
- 检查脚本：`scripts/check_questions.py`
- 版本：`1.0`
- 题量：40 题
- 题源：40 题均为 `IPIP`；每题均填写 `source` 与 `source_ref`
- 方向：每个维度第一极/第二极各 4 题
- ES 方向：严格使用 `stable` / `sensitive`

IPIP 官方页面说明其题库属于 public domain，并允许使用者翻译、改写、缩短和组合题项。本题库只保留了 IPIP 条目的语义依据，题干为面向中国年轻人生活场景的中文化改写。参考：
- [IPIP 50-item Big-Five Factor Markers](https://ipip.ori.org/new_ipip-50-item-scale.htm)
- [IPIP AB5C preliminary scale items](https://ipip.ori.org/newAB5CKey.htm)
- [IPIP Mini-IPIP scoring key](https://ipip.ori.org/MiniIPIPKey.htm)

## 40 题分布

| 维度 | 总量 | 第一极 | 第二极 |
|---|---:|---:|---:|
| EI | 8 | E：4 | I：4 |
| SN | 8 | S：4 | N：4 |
| TF | 8 | T：4 | F：4 |
| JP | 8 | J：4 | P：4 |
| ES | 8 | stable：4 | sensitive：4 |
| **合计** | **40** | **20** | **20** |

ID 按 `EI01–EI08`、`SN01–SN08`、`TF01–TF08`、`JP01–JP08`、`ES01–ES08` 排列；校验脚本同时检查 ID 唯一性。

## 题目示例

1. `EI01`：在不熟悉的同学组队时，你通常很快就能自然地聊起来。`source_ref`：IPIP-BFFM item #11 中文化场景改写。
2. `SN05`：看到一个点子时，你常会继续想它还能变成什么。`source_ref`：IPIP-BFFM item #25 中文化场景改写。
3. `ES05`：突然多出几项任务时，你很快就会觉得压力很大。`source_ref`：IPIP AB5C Stability facet 的 “Get stressed out easily.” 中文化场景改写。

### 2. 16 型可达性粗检

脚本为四个主线维度分别构造全选第一极或全选第二极的 8 题答案，覆盖 `2^4 = 16` 种组合。独立模拟命令：

```text
python -c "import json, itertools, pathlib; b=json.loads(pathlib.Path('data/questions/questions.json').read_text(encoding='utf-8')); by={d:[q for q in b['questions'] if q['dimension']==d] for d in ('EI','SN','TF','JP')}; poles={'EI':('E','I'),'SN':('S','N'),'TF':('T','F'),'JP':('J','P')}; reached=[]; [reached.append(''.join(poles[d][bit] for d,bit in zip(by,bits))) for bits in itertools.product((0,1), repeat=4)]; print('reachable_types =', len(set(reached))); print('types =', ','.join(reached)); assert len(set(reached)) == 16"
```

输出：

```text
reachable_types = 16
types = ESTJ,ESTP,ESFJ,ESFP,ENTJ,ENTP,ENFJ,ENFP,ISTJ,ISTP,ISFJ,ISFP,INTJ,INTP,INFJ,INFP
```
