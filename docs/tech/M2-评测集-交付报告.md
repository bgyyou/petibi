抽样策略：同 `public-speaking` 情境跨 INTJ / ESFP / ISFJ 三种不同气质人格 + `conflict` 下的 ENTP + `teamwork` 下的 ISTP，便于横向对比人格差异。

#### 3.2.1 样本 1 — INTJ × public-speaking

- **id**：`eval-intj-01`
- **question**：明天公司早会要做季度汇报，第一次面对 30 多号人讲 PPT，紧张到手心出汗，怕被挑刺，怎么办？
- **key_points**：
  - 提前写逐字稿并演练到能脱稿
  - 把演讲拆成几个核心信息点而非追求表演
  - 预判听众可能的质疑并准备好反驳数据
  - 上台前独处几分钟把思路再过一遍
- **source_entries**：`["INTJ-faq-public-speaking"]`
- **trap**：回答若给"深呼吸、放松点、想开心点"这类泛化减压建议，未触及 INTJ 真正需要的"结构化掌控感"

> 评注：key_points 全部围绕"结构化准备 + 预判 + 独处整理"，是 INTJ 的 Ni-Te-Fi-Se 典型应对；trap 明确指出"泛化减压"是该人格的真陷阱——盲评时若答非所问给鸡汤即可一眼判定。

#### 3.2.2 样本 2 — ESFP × public-speaking

- **id**：`eval-esfp-01`
- **question**：下周公司年会上让我上台讲 3 分钟感言，我脑子空白，看着台下 100 多人就慌，怎么办？
- **key_points**：
  - 准备 1 个最让你激动的故事或瞬间作为开场
  - 把台下的人想成"朋友聚会"而非"百人场"，降低压力
  - 允许自己笑着讲、哭着讲，真情实感比完美重要
  - 讲完就下台把话筒交给主持人，不恋战
- **source_entries**：`["ESFP-faq-public-speaking"]`
- **trap**：回答若建议"写逐字稿背到一字不差"——是 SJ 路径，ESFP 的即兴热情正是临场的王牌

> 评注：与 INTJ 样本对比鲜明——ESFP 走"故事 + 朋友感 + 真情"路径，反对"逐字稿死记"；两个 trap 互补，覆盖"鸡汤 vs 反人格"两类典型错误。

#### 3.2.3 样本 3 — ISFJ × public-speaking

- **id**：`eval-isfj-01`
- **question**：下周要在家长会上分享育儿心得，我准备了好多但怕讲太投入哭出来被别的家长看笑话，怎么办？
- **key_points**：
  - 选 1-2 个最能体现你真实感受的小故事讲透
  - 接受自己可能哭，把它当成"真情实感"而非"笑话"
  - 讲完后给自己留一段独处时间消化情绪
  - 把听众想成"跟我一样操心的父母"而非评审
- **source_entries**：`["ISFJ-faq-public-speaking"]`
- **trap**：回答若建议"强硬点、别那么情绪化、练到不哭为止"——是 T 型建议，ISFJ 的温柔共情正是其感染力来源

> 评注：同样写"真情流露"，但 ESFP 强调"故事 / 朋友 / 不恋战"，ISFJ 强调"接受哭 / 独处消化 / 听众共情父母"——气质可分。

#### 3.2.4 样本 4 — ENTP × conflict

- **id**：`eval-entp-02`
- **question**：开会讨论方案我提了个新点子被领导直接拍死，理由是"先按原计划来"，可我觉得他太保守，怎么办？
- **key_points**：
  - 会后用一份精简备忘录把"新点子的代价和收益"摆出来
  - 承认"保守"在某些场景合理，先做出原计划结果再说
  - 找机会在小型场合私下推广，让想法自然生长
  - 保留反叛精神但不硬刚，把"延后"变成"下次再说"
- **source_entries**：`["ENTP-faq-conflict"]`
- **trap**：回答若建议"既然领导说了就照做吧、不要多事"——这是顺从型建议，ENTP 应保留挑战精神但换打法

> 评注：key_points 既保留 ENTP 的"想法推广欲"，又教"换打法而非硬刚"，trap 抓"顺从盲从"——典型 ENTP 雷区。

#### 3.2.5 样本 5 — ISTP × teamwork

- **id**：`eval-istp-05`
- **question**：团队会议又臭又长我受不了，但我也不想显得格格不入，怎么办？
- **key_points**：
  - 会前把议题梳理成 1 页 A4 让讨论有结构
  - 用"我提一个具体建议"把会议拉回正轨而非发牢骚
  - 如果无效，私下跟 leader 提议优化会议形式
  - 保留对"行动导向"的偏好不被迫参加冗长会议
- **source_entries**：`["ISTP-faq-teamwork"]`
- **trap**：回答若建议"你应该配合团队节奏、多听少说"——是 SJ 路径，ISTP 应保留行动导向不被冗长拖垮

> 评注：与 ESFP / ENFP 那种"暖场破冰"完全相反——ISTP 走"压缩会议 + 优化形式 + 保留行动偏好"，trap 也精准指向"配合团队"这个反人格建议。

#### 3.2.6 横向差异小结（同情境 / 不同人格）

以 `public-speaking` 为例（INTJ / ESFP / ISFJ / ESTP 四型 trap 对比）：

| 人格 | trap 摘要 |
| --- | --- |
| INTJ | 泛化减压话术未触及"结构化掌控感" |
| ESFP | 写逐字稿背到一字不差（是 SJ 路径） |
| ISFJ | 强硬点别那么情绪化（是 T 型建议） |
| ESTP | 做 30 页 PPT 反复演练不要即兴（是 SJ 路径） |

四个 trap 都不同、且都指向"该人格最易被误解为通用建议"的反面——证明 trap 字段具备真正的"反鸡汤"区分力。

## 6. trap 字段的设计原则（写给盲评 agent）

为避免盲评时把 trap 当"标准答案"误用，约定如下：

1. **trap 不是"正确回答的反面"**，而是"该人格最易被误给的'伪人格 / 通用鸡汤'式回答"——用于识别"假人格绑定"。
2. 盲评打分时：
   - 若 AI 回答直接落入 trap 描述的"通用 / 反人格"模式 → 该条人格一致性扣分
   - 若 AI 回答覆盖 key_points 中的多数 → 该条人格一致性得分
   - 两类评估都对照本文件，不凭印象
3. 80 条 trap 互不重复的事实已在 §4 用脚本验证，可信。
