# 交付报告：美术工具脚本（pixelate / check_alpha）

> 对应工单：`docs/tech/M1-工单-美术工具脚本.md`
> 对应红线：R2（1-bit alpha）、R9（中文注释）；美术管线见 PRD §8.3
> 交付日期：2026-08-13

## 交付物

| 文件 | 说明 |
|---|---|
| `scripts/check_alpha.py` | 1-bit alpha 合规检查：递归扫描 PNG，统计半透明像素，按结果决定退出码 |
| `scripts/pixelate.py` | 即梦概念稿 → 合规 sprite：去背景（1-bit alpha 化）→ 裁剪缩放居中入 48×48 → 量化到 16 色板 |
| `scripts/tests/test_art_tools.py` | 自动化测试：PIL 程序生成四类边界测试图，跑两个脚本逐项断言 |

## 用法示例

```bash
# 检查默认目录（assets/ 和 resources/sprites/）下的全部 PNG
python scripts/check_alpha.py
# 检查指定目录（可多个）
python scripts/check_alpha.py assets/ resources/sprites/

# 概念稿 → 合规 sprite
python scripts/pixelate.py input.png -o output.png \
    [--alpha-threshold 128]   # 有 alpha 时的 1-bit 化阈值
    [--bg-tolerance 30]       # 无 alpha 时的背景色容差（四角均值为背景色）
    [--palette assets/style/palette.json]

# 运行测试（在仓库根目录）
python scripts/tests/test_art_tools.py
```

## 实现要点

- `check_alpha.py`：统一转 RGBA 后逐字节统计 `0 < alpha < 255` 的像素；目录不存在仅提示跳过；汇总 `半透明像素总数 = N`，N=0 退出 0 否则退出 1（供 CI 拦截）。
- `pixelate.py`：
  - 有 alpha 通道（RGBA/LA/带 transparency 的 P 模式）→ 阈值化 1-bit alpha，透明像素 RGB 清零（根治白边残留色）；
  - 无 alpha（如白底 JPG）→ 取四角像素均值为背景色，欧氏距离 ≤ 容差的区域置透明；
  - 按内容包围盒裁剪，最近邻（NEAREST，保像素硬边）等比缩放进 44×44 内容区，居中放入 48×48 透明画布（2px 边距）；输入小于 48 会等比放大；
  - 逐像素量化到 `assets/style/palette.json` 16 色中距离最近色；输出 RGBA PNG，alpha 严格只有 0/255。

## 测试结果（实跑）

环境：Windows，系统 anaconda Python 3.11.9，Pillow 12.1.1。

1. 自动化测试（命令 `python -W error::DeprecationWarning scripts/tests/test_art_tools.py`，加 `-W error` 确认无弃用 API 警告），输出：

   ```
   [OK] check_alpha 抓出半透明边的 PNG（退出码 1）
   [OK] check_alpha 对合规图退出码 0
   [OK] pixelate 处理带半透明边的 PNG（1-bit alpha + 16 色板）
   [OK] pixelate 白底 JPG 去背景正常（四角透明、主体保留）
   [OK] pixelate 纯透明 PNG 正常（输出全透明 48×48 画布）
   [OK] pixelate 小于 48px 的图等比放大居中（含 2px 边距）
   全部测试通过：PASS   （退出码 0）
   ```

2. 默认目录扫描（`python scripts/check_alpha.py`）：`半透明像素总数 = 0`，退出码 0（当前 assets/ 下尚无 PNG，resources/sprites/ 不存在按提示跳过）。

3. 手工 CLI 验证（程序生成 100×80 带半透明边（alpha=96）的图，`--alpha-threshold 64`）：输出 48×48，alpha 集合 = {0, 255}，不透明色全部落在色板内（如 #6B4E8E / #C9B4E0）。

覆盖的边界情况：带半透明边的 PNG、白底 JPG（无 alpha）、纯透明 PNG、小于 48px 的图，均已实跑通过。

## 遗留问题

- 逐像素 Python 循环处理，大图（如 1024×1024 概念稿）单次转换约数秒，对美术管线单张处理可接受；若未来需批量，可用 numpy 向量化（会引入新依赖，本工单约束仅用 Pillow，故未做）。
- 四角均值估背景色假设背景为纯色/近纯色；渐变底或主体贴到角落的图会误判，需要人工用 Piskel/Aseprite 修补（管线第 3 步本就有人工微调环节）。
- Windows 控制台默认 GBK，直接运行脚本时中文输出可能乱码，建议加 `PYTHONUTF8=1` 前缀（测试脚本内已对子进程处理）。
