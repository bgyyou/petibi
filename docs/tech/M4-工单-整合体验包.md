## 工单 A：前端体验整合（src/）

### A1. 百科 Tab 完整实现（src/panel/tabs/EncyclopediaTab.tsx）
- 16 人格列表页：形象图（portrait:read IPC 已有）+ 人格名 + 动物名 + 一句话特质（读 data/encyclopedia/<type>.json 的 trait-01）
- 详情页：分类展示百科条目（trait/cognitive/strength/weakness/career/relationship 分区 + faq 列表可展开）
- 族色作为该人格页面的主题色

### A2. 社区 Tab 完整实现（src/panel/tabs/CommunityTab.tsx）
- 广场：海报瀑布流/网格（GET /api/posters），点赞（POST like）
- 海报详情：留言列表 + 发留言（≤200 字，提示"审核后展示"）
- 未登录态：可浏览，点赞/留言时引导登录

### A3. 访客模式（src/setup/ + electron/）
- 登录页加「先逛逛」入口：不登录直接进入主面板（guest 模式：百科/社区可浏览，对话/测试入口显示"登录后解锁"）
- 主面板「我的」Tab 在 guest 模式显示登录引导
- guest → 登录后走正常初始化流程
- 启动分流逻辑调整：无 token 也非首次 → 记住 guest 选择（userData 存 guest 标记），不再每次强制登录

### A4. 快捷菜单（src/App.tsx + electron/main.ts）
- 单击桌宠 → 弹出小气泡菜单（贴桌宠位置，约 120×160 透明小窗）：跟我对话 / 主面板 / 隐藏桌宠
- 「跟我对话」直接开主面板并定位到对话 Tab
- 点击其他区域菜单消失；拖拽不触发（沿用 ≤5px 阈值）

### A 自验
- vitest 不回归 + typecheck 0 错 + build:app 通过 + check_comments 通过
- 访客模式全路径实测（guest 逛百科/社区 → 登录 → 初始化 → 对话）

## 工单 B：多轮对话上下文（server/）

### B1. 会话记忆
- chat 接口接 conversation：客户端传 session_id；server 从 chat_logs 取该 session 最近 6 轮（question+answer）拼进 prompt 上下文（基础层之后、用户问题之前）

### B2. 自验
