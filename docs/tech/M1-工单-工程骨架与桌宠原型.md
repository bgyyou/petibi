# 工单：Electron 工程骨架 + 悬浮窗桌宠原型

> 里程碑：M1 | 执行：子 agent | 验收：主 agent
> 对应红线：R1（可构建）、R2（透明窗）、R9（中文注释）

## 目标

搭建可构建、可打包的 Electron 应用骨架，实现透明无边框悬浮窗，窗内有一只可拖拽、可播放三状态帧动画的像素桌宠（占位 sprite）。

## 技术决策（已定，照做即可）

- 栈：Electron + electron-vite + React + TypeScript
- 打包：electron-builder（Windows NSIS）
- 桌宠窗：`transparent: true, frame: false, alwaysOnTop: true, resizable: false, skipTaskbar: true`
- 拖拽：透明窗不能用 `-webkit-app-region: drag`（点击区域不可靠），用鼠标事件 + `win.setPosition()` 自实现
- 显示尺寸：sprite 48×48 放大 4 倍显示（192×192），CSS `image-rendering: pixelated` 保持锐利
- 动画：8fps 逐帧切换 PNG，三状态 idle / blink / happy，右键菜单或快捷键切换状态（调试用）

## 目录结构

```
MBTIwilldo/
├── electron/          # 主进程
│   └── main.ts        # 创建透明悬浮窗、IPC
├── src/               # 渲染进程（React）
│   ├── App.tsx        # 桌宠组件：帧动画播放器 + 拖拽
│   └── ...
├── resources/sprites/placeholder/   # 占位 sprite（idle/blink/happy 各 2-4 帧 PNG）
├── scripts/           # 工具脚本（另一工单负责，本工单只需不冲突）
├── package.json
└── electron-builder.yml
```

## 占位 sprite

用 Python/PIL 写一个 `scripts/make_placeholder.py` 生成：48×48 纯色圆角小怪兽（用 `assets/style/palette.json` 分析家族紫色系），idle 2 帧（身体差 1px 呼吸感）、blink 2 帧（眼睛闭/睁）、happy 2 帧（嘴巴笑）。透明背景，1-bit alpha。

## 验收标准（逐条过）

1. `npm install && npm run build` 成功，`release/` 产出 Windows 安装包或可执行目录
2. `npm run dev` 启动：透明无边框窗悬浮在桌面上，桌宠可见，壁纸透出来
3. 鼠标按住桌宠可拖动，松手停住
4. 三状态动画 8fps 播放正常，切换有效
5. 所有源文件有中文文件头注释 + 函数中文注释（R9），`python scripts/check_comments.py` 通过（若脚本尚未存在，本工单一并实现其扫描规则：每个 .ts/.tsx/.py/.js 文件前 5 行内有中文文件头注释块）
6. 静置内存 < 300MB（任务管理器看一眼，记录数值即可）

## 约束

- 全程中文注释（R9：文件头 + 函数 + 复杂逻辑逐行）
- 不要引入 UI 组件库（antd/mui 等），桌宠窗用不上，保持轻量
- 网络环境为中国大陆，npm 如有问题可配 taobao 镜像
- 完成后在 `docs/tech/M1-桌宠原型-交付报告.md` 写明：做了什么、怎么验证的、验收 6 条逐条结果、遗留问题
