## 没把握的（诚实标注）

1. **infp 蝴蝶（最大保留项）**：6 次生成 image-01 都画不出字面昆虫头，选定造型是"戴绿兜帽的生物感脸"（无毛无发、巨大复眼、触角、橘翅），兽首可读性弱于其他 15 只。若 owner 要求字面蝴蝶头，**建议即梦出稿**后走同一 finalize 管线。
2. **esfj 大象成了"白象"**：候选的浅灰皮肤量化后落到白/奶油（色板 neutrals 内合法），不是预期的灰象。视觉协调，但如要灰象需重生成深色皮候选。
3. **探险家族头区以外的身体毛色**（esfp 腿、estp 手臂、istp 尾巴）可能带少量本族琥珀色调——头区已机械中性化，身体上服装与毛无法机械区分，未处理。校验脚本只卡头区，此处依赖目检，目前目视无可感知的黄/橘异常（橘本身是 neutrals 合法色）。
4. **intj 猫头鹰是"紫兜帽里的猫头鹰脸"**、isfp 卡皮巴拉是"琥珀兜帽 + 动物脸"：兽首可读但带兜帽造型，与 entj/estj 等全裸兽首的构图略有差异（16 张构图均为 Q 版正面全身居中，兜帽差异在服装层）。
5. AI 伪像素画经 256 网格吸附 + 量化后，个别图（enfp 夹克、isfp 罩衣）色调分区变平，细节主要靠描边和色块边界保留；无严重脏噪点（洪水抠背景 + 碎屑清理有效，签名水印已抹除）。512 画布 + 2px 网格这个规格本身没发现问题，无需退到 256 画布。
