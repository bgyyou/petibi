## 三、像素化与帧生成规则

### 3.1 基准帧（base.png）
- 由 `assets/art/portraits/<type>.png`（512×512 RGB）经 `pixelate.py --size 64` 处理
- 复用 `pixelate.py` 全部规范：1-bit alpha + 限定色板 + 最近邻缩放 + 2px 边距

### 3.2 idle 帧（Shimeji 规范）
```
idle_0 = base 原样
idle_1 = base 经 make_idle_1():
         - 头部 [y0, head_end) 像素保持 0 改动
         - 躯干下移 1px（从 head_end-1 取源，向下借 1 行避免与头脱节）
         - 腿丢顶 1 行（脚不动 / 腿短 1px）
```
- 头/腿边界由 `HEAD_RATIO=0.45` / `LEG_RATIO=0.22` 切分（沿用 make_idle.py 经验值，2.5 头身 Q 版）
- bbox 与脚底 y 坐标两帧完全一致 → "基准点对齐"

### 3.3 blink 帧
- 自动定位眼睛行：在头部区域内寻找"暗像素密集 + 亮像素共存"的行（前 2 行）
- 把该行的所有不透明像素替换为色板 `outline` 色（#2B2320）
- 视觉上呈现为"一道横线"= 闭眼

### 3.4 thinking 帧
- 任务允许"复用 idle + 可选 ≤1px 轻摇"
- 当前实现：thinking_0/1 直接复用 idle_0/1（不做横向位移，避免 sprite 边缘锯齿/空白）
- 决策依据：动画相位差异由 IPC 通知上层渲染处理（即使 1px 横向位移也会在低分辨率 sprite 上产生明显的左/右错位感）

## 五、64px 下细节偏弱的精灵（诚实清单）

通过逐只头部填充率（"头部不透明像素 / 头部包围盒面积"）评估，**填充率最低的两只是 INFJ 和 ESFJ**：

| type | bbox | 头部填充率 | 评估 |
|---|---|---|---|
| **INFJ**（天鹅） | 36×60 | **23.7%** | ⚠️ 最弱：天鹅长颈 + 细长头部形象本身偏稀疏，64px 下头部"特征像素"少，眼睛和喙都偏小（仅 17 个头部暗像素）；视觉上可能偏淡。 |
| **ESFJ**（大象） | 56×60 | 42.5% | 大象身体宽（56px 接近画布满宽），但头部周围有大量留白；眼睛/象牙细节像素分布稀疏，64px 下鼻子的弧线可能不够明显。 |
| INFP（蝴蝶） | 40×60 | 48.6% | 蝴蝶翅膀细密，64px 下触角和翅膀纹路可能糊在一起；建议目检时重点看是否需要追加一点翅膀高光色。 |
| ENFP（海豚） | 36×60 | 56.4% | 海豚流线型身体特征本身简单，眼睛和嘴线在 64px 下勉强可读。 |
| ESFP（鹦鹉） | 34×60 | 56.5% | 鹦鹉羽毛色块较多，主体色填充中等，但喙/眼睛细节偏小。 |

**头部细节最丰富的 5 只**（填充率 ≥ 80%）：ENFJ、ENTJ、ISTP、ESTJ、INTJ——这些是阔面、有胡须/鬃毛等粗特征的角色，在 64px 下非常清晰。

**建议 owner 目检 sprite-sheet-64.png 时重点看 INFJ、ESFJ、INFP 三只**，如果觉得糊再决定要不要回炉做 v3 形象图（不动 64×64 衍生流程）。
