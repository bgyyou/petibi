# 工单：16 人格精美像素形象图（大画布版 v4）

> 里程碑：M1 补充 v4 | 执行：子 agent（MiniMax M3） | 验收：主 agent + owner 目检
> owner 原话："说的是像素风，不是低像素风。人物细节要做得很精美，只是风格是像素风。"

## 交付物定义（owner 明确，顺序不许反）

1. **先交付 16 张人格形象图**：统一 512×512 画布，精细像素画（pixel art 风格，颗粒感保留，但细节丰富——毛发纹理、服装褶皱、表情都要做出来）
2. **16 张全部定稿后才拼 sprite-sheet**（从定稿形象图拼接，不许提前拼）

## 设计规范

- 形态：兽首人身（Q 版 2.5 头身，正面或 3/4 侧面，全身或半身像均可，但 16 张构图必须统一）
- **毛色规避四族色**：动物头/毛色禁止使用 绿/黄/紫/蓝 四族色系，只用 `assets/style/palette.json` 的 neutrals 组（白/奶油/浅棕/棕/深棕/灰/深灰/橘）。特别注意：
  - ENFP 海豚：蓝色 → 改灰色系
  - ESFP 鹦鹉：绿色 → 改红橘色系（金刚鹦鹉方向）
  - ISFJ 企鹅：黑白（深灰+白）
  - INFJ 天鹅：白/奶油
- **人格色系只体现在服装/配饰**：服装主色 = 该人格 family 的 main（见 palette.json，一族一色，同族 4 人完全同色拉齐）
- 背景：纯色（白 #FFFFFF 或透明），禁止场景、投影、渐变背景

## 执行步骤

1. 设计 prompt 模板（image-01，API 用法同前工单）：关键词必须含 "detailed pixel art"、"512x512"、"crisp pixels, no anti-aliasing"、指定动物 + 毛色 + 服装色 hex、纯白背景。先拿 2 只试跑调模板，模板稳定后批量。
2. 每只 2-3 候选存 `assets/art/concepts/v4/`。
3. 选片 + 合规化：写一个量化脚本（可复用 pixelate.py 思路但**不缩放**，只把颜色映射到色板 families+neutrals+outline；需要的话给 pixelate.py 加 `--no-resize` 模式）。白底保留或转透明均可，但 16 张统一。
4. 逐张校验：颜色全部在色板内；动物毛色不含四族色（写脚本扫头部区域色相，或逐张目检确认）；同族服装色完全一致。
5. 产出 `assets/art/portraits/<人格>.png`（16 张 512×512）。
6. **owner 目检通过后**（报告里说明等待 owner 确认），再拼 `assets/art/portrait-sheet.png`（4×4）。
7. 中文注释（R9）、不 commit、不动 PRD/REVIEW/ISSUES/plan.md、不动 `resources/sprites/`（桌宠小图本轮不动）。

## 验收标准

1. 16 张 512×512 形象图，细节丰富度明显超越 v2 的 32×32（毛发/褶皱/表情可读）
2. 毛色零四族色；同族服装色像素级一致
3. 全部颜色在色板内（量化后校验脚本输出）
4. sprite-sheet 在 16 张定稿后拼接
5. 交付报告 `docs/tech/M1-形象图-v4-交付报告.md`：每只候选数、返工次数、毛色处理、没把握的（诚实标注）

## 诚实义务

- image-01 对 "detailed pixel art" 的执行力可能不稳，某只 5 次仍不行的标注"建议即梦出稿"
- 如果 512×512 量化后细节损失严重（AI 出的伪像素画量化会脏），如实报告并给出替代建议（如 256×256 画布、或只量化头部/只量化服装分区处理）
