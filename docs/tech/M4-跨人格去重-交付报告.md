## 同族差异化抽样（绿族 NF：INFJ / INFP / ENFJ / ENFP）

主题：`faq-alone-weekend`（一个人过周末）——四人都是 NF 内倾/外倾 + 直觉主导，独处时遇到的困难完全不同。

**INFJ**：
> INFJ 的独处像一次次内部整理——Ni 在安静里更新远景图，Fe 在这个过程里安静下来不再向外扫。主动给自己留大块独处时间，是可持续社交的前提。把独处时间前置留好，比事后硬补更省；Fe 不是无限产能的发电厂，是需要定期维护的电池组，独处就是给电池组做维护的关键时段。

**INFP**：
> 作为 INFP，独处时容易陷入过去的回忆和反刍。准备一个『接地气』的小事清单：做饭、整理、写信，独处时有抓手能避免过度反刍进入情绪低谷。INFP 独处时陷入回忆是 Si + Fi 的反刍搭档，准备『接地气』小事清单把 Fi 切到当下动作——抓手不是压抑，是给反刍设边界。

**ENFJ**：
> ENFJ 周末独处半天就开始想『是不是该去看看谁』，结果是出门赴约回来更累——Fe 的连接欲一刻不停，Ni 的远景图反而没空间展开。每周留 4 小时完全不联系任何人——纯休息不是冷场，Ni 才有空间铺自己的远景，否则总在别人的情绪里来回跑。

**ENFP**：
> ENFP 自己待超过一天就开始坐不住——Ne 是台停不下来的联想机，没人对话时它会自己跟自己辩三轮然后空虚。提前备一个『单人也能玩』的小事清单——咖啡馆翻书、城市里 walk、做饭时录一段直播，把刺激的来源从『找人聊天』切到『做有正反馈的小事』；独处才不会变成焦虑，Ne 才有地方跑。

四人差异：
- INFJ 独处 = 内部整理（Ni + Fe 安静下来）
- INFP 独处 = 容易反刍（Si + Fi 搭档），需要抓手切回当下
- ENFJ 独处 = 忍不住想出门（Fe 连接欲 + Ni 没空间展开）
- ENFP 独处 = 自己跟自己辩（Ne 停不下来），需要外部刺激源切换

四条答案都基于各自的认知功能组合给出不同的应对策略，跨条目无 10-gram 公共子串。

主题：`faq-breakup` —— 分手后的恢复路径。

- INFJ 把前任符号化为唯一灵魂伴侣（Ni + Fe 把神化放大）
- INFP 触发『我是否值得被爱』的底层议题（Fi 的核心议题）
- ENFJ 第一反应是担心对方能不能过好（Fe 把对方幸福当未完成承诺）
- ENFP 表面断崖式回升，但夜里 Ne 反刍没人看见
