# 工单：美术工具脚本（pixelate / check_alpha）

> 里程碑：M1 | 执行：子 agent | 验收：主 agent
> 对应红线：R2（1-bit alpha 检查）、PRD §8.3 美术管线

## 目标

实现美术管线的两个 Python 脚本，让"即梦概念稿 → 合规 sprite"半自动化。

## 环境

- 系统 Python（anaconda），Pillow 已装或 `pip install pillow`（可用清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple`）

## 脚本 1：`scripts/check_alpha.py`

- 功能：递归扫描指定目录（默认 `assets/` 和 `resources/sprites/`）的所有 PNG，检查是否存在半透明像素（0 < alpha < 255）
- 输出：每个文件一行结果；末尾汇总"半透明像素总数 = N"
- 退出码：N=0 退出 0，否则退出 1（供 CI/验收用）

## 脚本 2：`scripts/pixelate.py`

- 功能：即梦概念图 → 合规 sprite 的转换
  1. 读入任意尺寸图片
  2. 背景处理：若图有 alpha 通道，把 alpha 阈值化为 1-bit（阈值可用 `--alpha-threshold` 调，默认 128）；若无 alpha，把与四角颜色相近（容差可调）的区域置为透明
  3. 等比缩放到 48×48 内（保持长宽比，居中，留 2px 边距）
  4. 颜色量化到 `assets/style/palette.json` 的 16 色（每像素映射到最近色）
  5. 输出 PNG（RGBA，但 alpha 只有 0/255 两种值）
- CLI：`python scripts/pixelate.py input.png -o output.png [--alpha-threshold 128] [--bg-tolerance 30]`
- 边界：输入已有透明背景、输入是纯白底、输入尺寸小于 48，三种情况都要正常处理

## 测试

在 `scripts/tests/` 用 PIL 程序生成测试图（带半透明边的 PNG、白底 JPG、纯透明 PNG），跑两个脚本验证：check_alpha 能抓出半透明；pixelate 输出严格 1-bit alpha 且只含色板颜色。
