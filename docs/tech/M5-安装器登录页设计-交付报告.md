## 3. 任务 2：登录页设计升级

### 3.1 现状与目标

- **现状问题**（owner 实测）：登录页中部留白大、无品牌感、缺少视觉锚点。
- **目标**：在 form 上方加入 16 人格像素形象墙 + Petibi logo + 主 slogan「遇事不决，问问你的人格」。

### 3.2 实现要点（`src/setup/pages/LoginPage.tsx` 重写）

**结构**（自上而下）：
1. **品牌区**：12×12 像素 logo（紫 + 绿双色 24×24 容器，3px 墨边框 + 硬阴影）
   + Slogan「遇事不决，问问你的人格」（像素字体 22px）+ 副标题
2. **16 人格像素形象墙**（4×4 网格）：
   - 顺序按 `src/setup/persona-meta.ts` PERSONAS（4 族 × 4 字母）
   - 每格：族色底纹 + 3px 墨边框 + 硬阴影 + 4px 族色顶条
   - sprite 48×48 通过 `window.petApi.getSpriteDataUrl(type, 'idle_0')` IPC 加载
     （与 EncyclopediaTab / ResultPage 同源，`loadSpriteDataUrl` + `spriteDataUrlCache` 模块级 singleton）
3. **像素分隔线**（`<hr className="pixel-divider">`，DESIGN.md §3 装饰可用）
4. **原登录表单**：邮箱 + 验证码 + 发送按钮 + mock banner + error banner（功能完全不动，只调视觉）
5. **页脚**：登录协议 + "先逛逛（不登录）" + "下一步" 按钮

**关键约定**：
- sprite 加载：与 EncyclopediaTab 同源（懒加载 + 缓存 + 占位）
- 验证逻辑（`EMAIL_RE` / `codeValid` / devCode / 老用户直通 / 新用户 LOGIN_SUCCESS）完全保留
- dev / mock 模式横幅保留（`mock-banner` class 已存在）
- 自绘标题栏保持不变（DESIGN.md §6，TitleBar 由 App.tsx 包好）
