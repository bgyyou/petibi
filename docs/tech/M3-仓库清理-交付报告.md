## 8. 遗留说明

- 本批改动**未 git commit**，按要求交由 owner 审阅后处理。
- `scripts/_archive/` 内脚本仍带 `sys.path.insert(__file__.parent)`，即已归档脚本之间的互相 import（如 `remap_inner_layer_v5` → `remap_portraits_v5`）在归档目录内仍可解析；但它们对 `scripts/` 主目录模块（如 `make_concepts`、`gen_portraits_v4`）的 import 在归档后不再解析。这些脚本均为一次性、不再运行，视为可接受；若日后需重跑，拷回 `scripts/` 即可。
