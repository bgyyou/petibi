# 交付报告：Electron 工程骨架 + 悬浮窗桌宠原型

> 对应工单：`docs/tech/M1-工单-工程骨架与桌宠原型.md`
> 对应红线：R1（可构建）、R2（透明窗 / 1-bit alpha）、R9（中文注释）
> 交付日期：2026-08-13

## 交付物

| 文件 | 说明 |
|---|---|
| `electron/main.ts` | 主进程：创建透明无边框悬浮窗（192×192），IPC 处理拖拽位移与右键状态菜单 |
| `electron/preload.ts` | 预加载：contextBridge 暴露 `window.petApi`（drag / showMenu / onSetState / notifyState） |
| `src/App.tsx` | 桌宠组件：三状态 8fps 逐帧动画 + 鼠标拖拽 + 右键菜单 / 数字键 1、2、3 切换状态 |
| `src/main.tsx`、`src/index.html`、`src/pet-api.d.ts` | 渲染进程入口、透明页面、预加载 API 类型声明 |
| `electron.vite.config.ts`、`tsconfig.json`、`electron-builder.yml` | 构建 / 类型检查 / NSIS 打包配置 |
| `scripts/make_placeholder.py` | 生成占位 sprite：48×48 紫色圆角小怪兽，idle/blink/happy 各 2 帧，透明背景 1-bit alpha |
| `scripts/check_comments.py` | R9 检查：每个 .ts/.tsx/.py/.js 前 5 行内须有中文文件头注释 |
| `resources/sprites/placeholder/*.png` | 6 帧占位 sprite（由生成脚本产出） |

## 实现要点

- **拖拽**：透明窗不能用 `-webkit-app-region: drag`，按工单用鼠标事件 + IPC 增量位移实现：渲染进程把 `screenX/screenY` 增量发给主进程，主进程 `win.setPosition()` 叠加。
- **sprite 引用**：`resources/` 配置为渲染进程 `publicDir`，dev 下 `/sprites/...` 可访问，打包时原样拷贝进 `out/renderer/sprites/`，React 用相对路径引用，dev / 打包行为一致。
- **后台节流坑（实测踩到）**：桌宠窗常年无焦点，Chromium 默认把 `setInterval` 钳制到 1Hz，8fps 动画变 1fps（实测间隔 400ms 两帧无差异，间隔 1.2s 才有变化）。已在 `webPreferences` 加 `backgroundThrottling: false`，修复后间隔 400ms 两帧即有差异。
- **菜单勾选一致性**：键盘切换状态不经过主进程菜单，导致右键菜单单选勾选项过期。补了 `pet:state-changed` 回告 IPC，渲染进程状态变化即同步主进程。
- **占位 sprite**：PIL ImageDraw 无抗锯齿，alpha 天然只有 0/255；颜色全部取自 `assets/style/palette.json` 分析家紫色系四档；idle 两帧身体差 1px 模拟呼吸。
- **check_comments.py 判定规则**（两段式，兼容 docstring / 块注释中间行无注释标记的情况）：前 5 行至少一行含 CJK 中文字符，且至少一行带注释标记（`//`、`#`、`/*`、三引号等）或以 `*` 开头；排除 node_modules/out/release/dist 等产物目录；覆盖率 100% 退出 0 否则退出 1。

## 遗留问题

- **截屏工具抓不到本窗口**（非产品缺陷）：Windows BitBlt 系截图（`CopyFromScreen`、部分截图软件）不含硬件加速的 DirectComposition 透明窗，验收截图需用 Desktop Duplication（本报告用 dxcam）。肉眼目视显示完全正常；若未来要做自动化截图测试，注意避开 BitBlt。
- electron-builder 提示 `author is missed in the package.json`、使用默认 Electron 图标——上架前需补 author 与应用图标（属官网发布工单范围）。
- 占位 sprite 仅用于跑通管线，风格基准动物未定稿（属美术资产工单）。
- 安装包未签名（无证书），Windows SmartScreen 会拦截提示，M1 阶段可接受。
