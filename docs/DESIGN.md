# Petibi 设计规范（DESIGN.md）

> 版本：v1（2026-08-13 owner 拍板：像素艺术风打底 + 孟菲斯调味）
> 用途：所有界面返工/新建的唯一视觉依据；M3 施工时必须逐条遵守，交付前过自检清单
> 来源：StyleKit「像素艺术风」硬性提示词为主体，配色与装饰规则已替换为 Petibi 自有资产

---

## 1. 核心理念

**治愈像素**：街机像素的"形"（无圆角、像素边框、硬边阴影、像素装饰）+ 孟菲斯的"暖"（奶油底色、活泼小装饰）+ Petibi 四族色的"魂"。界面与像素桌宠是同一套视觉语言。

三条原则：
- **像素感**：锐利边缘、像素化装饰元素（星星、虚线、点阵）
- **暖**：奶油白底、柔和族色，不要霓虹刺眼
- **一致**：所有窗口（初始化/主面板/安装器）同一规范

## 2. 色板（UI 用，与美术色板同源）

```
墨（描边/正文）:  #2B2320   ← 与 sprite outline 同色
奶油（背景主色）: #FEF9EF   ← 孟菲斯底
纸白（卡片）:     #FFFFFF
四族强调色:       紫 #785D87 / 绿 #3E8F6E / 蓝 #399FB9 / 黄 #E4C728
辅助文字:        #8B8680
```

规则：强调色只用四族色；页面主题色跟随当前人格族色（CSS 变量 --family-color）；禁止引入色板外颜色。

## 3. 硬性规则（禁止项 = 最高优先级）

- **禁止圆角**：一律 `rounded-none`（唯一例外：头像/形象图容器可用 2px）
- **禁止渐变**：纯色块
- **禁止柔和阴影**：只用硬边偏移阴影
- **边框**：统一 3px（border-4 在桌面小窗太粗）墨色实线
- **阴影**：`4px 4px 0 #2B2320`（卡片/按钮），hover 时 `2px 2px 0` + 位移 2px，active 时阴影消失 + 位移 4px；过渡 `transition-all duration-100`
- **禁止 emoji 当功能图标**：用像素图标或文字（🎨 这类要换成像素绘制 icon）
- **装饰**：像素星星、点阵、虚线分隔线可用；几何装饰（孟菲斯圆形/三角）仅限海报和官网落地页

## 4. 字体

- **标题**：缝合像素字体（Fusion Pixel，SIL OFL 开源可商用）——需下载字体文件打包进 assets
- **正文**：系统黑体栈（PingFang / Microsoft YaHei），字重 regular/medium
- **字号**：H1 24 / H2 18 / 正文 14 / 小字 12（桌面应用尺度，不照搬 web 的 md: 响应式）
- 英文/数字标题可 uppercase + tracking-wider；中文不做字间距拉伸

## 5. 组件规则

- **按钮**：纸白或族色底 + 3px 墨边框 + 硬阴影 + hover/active 位移反馈
- **卡片**：纸白底 + 3px 墨边框 + 4px 硬阴影
- **输入框**：纸白底 + 3px 墨边框，focus 时内描边 2px 族色
- **标签/角标**：族色实底白字，无圆角
- **Tab 栏**：底部或顶部像素分隔线，激活项族色下划线 3px

## 6. 窗口与安装器

- **全部窗口无边框**（frame:false）+ 自绘标题栏：28px 高、奶油底、左侧 Petibi 像素 logo + 标题、右侧自绘最小化/关闭像素按钮（16×16 icon）、标题栏可拖拽（app-region: drag）
- **NSIS 安装器**：一键安装模式（去掉"为哪位用户安装"页）+ 左侧 164×314 品牌插画（像素风 16 人格全家福，AI 出稿）+ 自定义图标 + 完成页引导启动

## 7. 交付自检清单（M3 每个界面交付前必过）

- [ ] 无圆角 / 无渐变 / 无柔和阴影（全局搜索 rounded-lg|gradient|shadow-lg 为零）
- [ ] 边框统一 3px #2B2320
- [ ] 强调色全部来自四族色板
- [ ] 标题用像素字体、正文黑体
- [ ] 按钮/卡片/输入框符合组件规则
- [ ] 无 emoji 功能图标
- [ ] 窗口自绘标题栏、无系统默认边框
