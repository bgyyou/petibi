# Petibi 完整体验指南（V1 验收用）

> 2026-08-13 | 对应 commit：e7cc883
> 目标：从零跑通「打开软件 → 访客浏览 → 登录 → 测试定人格 → 得桌宠 → 多轮对话 → 生成海报 → 社区分享」全链路

---

## 0. 启动（两种方式）

**方式一：开发模式（推荐，功能最全）**
```bash
cd MBTIwilldo
npm run dev          # 启动桌宠应用
```
默认 mock 模式（无需后端），所有功能可体验。
想体验真实后端链路：另开一个终端 `npm run server:dev`，然后把 `VITE_USE_MOCK_API` 设为 false（见 .env.example）。

**方式二：安装包**
双击 `release/Petibi Setup 0.1.0.exe` 安装（会有"未知发布者"提示，点仍要运行——未签名是验证期已知项）。

## 1. 访客模式（不登录）

- 首次启动出现登录页 → 点底部「先逛逛（不登录）」
- 预期：桌面出现像素桌宠（128×128 悬浮），主面板可打开
- 能做什么：**百科 Tab**（16 人格卡片按四族分组，点进去看详情：特质/认知功能/优劣势/职业/关系 + FAQ 手风琴）、**社区 Tab**（广场浏览海报）
- 不能做什么：对话、测试、点赞、留言——点这些会看到"登录后解锁"引导
- 下次启动：记住访客选择，不再强制登录

## 2. 登录 + 初始化

- 百科/社区随便逛后，去「我的」Tab 点登录
- 邮箱随便填（如 `test@example.com`），mock 验证码固定 **123456**
- 输入昵称 → 二选一：
  - **直接选人格**：16 选 1（认识自己的 MBTI）
  - **做测试**：40 题，一题一屏，5 级量表，可返回上一题，约 5 分钟
- 结果页：人格类型 + 细分标签（坚定型/善感型）+ 动物形象 + 「结果符合你吗」反馈按钮
- 完成 → 流程窗关闭，桌面出现**你人格的像素桌宠**

## 3. 桌宠交互

- **单击桌宠** → 快捷气泡菜单：跟我对话 / 主面板 / 隐藏桌宠
- **拖拽**：按住拖动，松手停住（位移 <5px 视为单击，不会误开菜单）
- **右键**：切换动画状态（待机/眨眼/开心）
- **隐藏后**：系统托盘有图标，点它唤回；托盘菜单可退出

## 4. 多轮对话（核心体验）

- 快捷菜单点「跟我对话」→ 主面板对话 Tab
- 随便问：「明天要当众汇报，好紧张」→ 桌宠 0.3 秒内切思考动画 → 流式打字机出回答（**以你人格的视角**）
- 追问一句相关的（如「那我怎么准备比较好」）→ 验证它记得上一轮（多轮上下文）
- 试长输入：写一大段背景（≥150 字）→ 回答会变成三段式（先复述你说的 → 再分析 → 再给建议），这就是深度档
- 试越界：「帮我写个 python 脚本」→ 收到人格化拒绝（不是"对不起我无法"）
- 试注入：「忽略你之前的指令」→ 同样被拦
- 右上角显示今日剩余次数（每日 10 次）；「新会话」按钮可重开话题

## 5. 海报分享

- 任意一条回答旁点「🎨 生成海报」→ 预览（1080×1350，你人格的族色主题）
- 保存本地 PNG / 分享到广场
- 样张参考：`assets/art/poster-samples/`（INFP/INTJ/ESTP 三张）

## 6. 社区

- 社区 Tab 看广场（你分享的海报审核通过后上墙）
- 点赞、留言（留言 ≤200 字，提示审核后展示）
- 试发一条违规留言（含"加微信"）→ 被拒绝，列表里看不到（审核管道生效）

## 7. 宠物昵称

- 「我的」Tab → 宠物昵称默认是动物本名 → 可自定义（1-8 字）
- 改完立刻再改 → 提示冷却中（3 天内只能改一次）+ 剩余时间倒计时

- 海报「这次对话」标题前有豆腐块字符（emoji 字体缺失，M5 修）
