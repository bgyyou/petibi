# Petibi 16 人格桌宠角色设计文档（兽首人身版 v1）

> 依据：PRD §8、工单 `docs/tech/M1-工单-16人格sprite设计.md`、色板 `assets/style/palette.json`
> 本文档是后续所有美术生产（PIL 程序化绘制 / 即梦概念稿 / Piskel 微调）的统一依据。

## 0. 全局硬规范（16 只共用）

- **画布**：32×32，四周留 2px 边距，内容区 28×28（x 2..29，y 2..29）；显示 ×4 = 128px
- **头身比**：2.5 头身。头部（动物头）占 y 2..14（约 13px 高），身体占 y 15..29（15px）
- **共用骨架**（16 只完全一致，只换头和衣服配色）：
  - 头：水平居中（中心 x=15/16），宽 14~18px（随动物特征变化），y 2..14
  - 躯干：x 11..20（10px 宽），y 15..23（9px 高），衣服填充
  - 手臂：x 9..10 / x 21..22（各 2px 宽），y 16..22，贴躯干两侧
  - 腿：左 x 12..14 / 右 x 17..19（各 3px 宽），y 24..29，中间 x 15..16 留缝
  - 鞋：腿最底部 2px（y 28..29）用族内最深色
- **描边**：全部外轮廓 1px，统一 `#2B2320`（outline）
- **光源**：统一左上。头部左侧/上侧用浅一档提亮，右侧/下侧用深一档压暗
- **alpha**：1-bit（只有全透明 / 全不透明），禁止抗锯齿过渡像素
- **用色纪律**：全部颜色必须落在 16 色色板 + outline 内。
  - **衣服 = 人格专属主色**（palette.json `personalities[].main`），这是人格品牌识别色
  - **动物头 = 板内最接近该动物真实毛色的颜色**（允许跨族借色，仅限头部）——
    动物辨识度优先；人格色彩识别由衣服承担
  - 瞳孔 / 鼻孔 / 嘴线 = outline；眼白 / 高光 = 浅色系板内色
- **idle 2 帧呼吸**：帧 1 = 头不动、脚不动，躯干和手臂整体下移 1px（腿被压缩短 1px）。
  两帧包围盒完全一致（y 2..29），保证过 pixelate.py 时是恒等变换，不被二次缩放

## 1. 分析家（紫族）

### INTJ 建筑师 × 猫头鹰（主色 #3B2A4A）
- **气质**：冷静、洞察、不动声色
- **头部像素设计**：头用棕黄 `#A8763E`（真实猫头鹰羽色）。**耳羽**是灵魂：头顶左右各一撮 2×3px 的尖三角羽簇（`#6B4A1F`），从 y 2 起。**大圆眼**：左右各一个 4×4px 浅色眼盘（`#F0CE9B`），盘中央 2×2px 瞳孔（outline），两眼间距 2px——猫头鹰的"瞪视"全靠这对大圆盘。眼盘下方中央一个 2px 向下的喙尖（`#D4A55F`）。头部右下缘用 `#6B4A1F` 压一圈阴影
- **衣服**：深紫 `#3B2A4A` 高领长袍感，胸前 1px 浅紫 `#9B7EC4` 竖线当衣襟

### INTP 逻辑学家 × 猫（主色 #6B4E8E）
- **气质**：慵懒、神游、若有所思
- **头部像素设计**：橘猫 `#D4A55F`。**三角耳**：头顶左右各 3×3px 三角耳，耳尖 1px 深棕 `#A8763E`。**半眯眼**：不做圆眼，做两条 3×1px 的横线眼（outline），上眼睑压平——猫的慵懒感全靠眯眼。口鼻区 3×2px 浅米 `#F0CE9B`，中央 1px 鼻点（outline），左右各 2 根 1px 胡须（横线 2px，outline）
- **衣服**：紫 `#6B4E8E` 宽松卫衣，领口 1px 浅紫描边

### ENTJ 指挥官 × 狮子（主色 #9B7EC4）
- **气质**：威严、掌控、领袖气场
- **头部像素设计**：脸盘 `#D4A55F`，**鬃毛**是灵魂：脸外围一圈 3px 厚的深棕鬃毛环（`#A8763E`，外缘再 1px `#6B4A1F` 锯齿），鬃毛把脸挤成中央 8×8px 的圆脸——鬃毛环使狮头是 16 只里最宽的头（18px）。鬃毛顶部两侧各露出 2×2px 圆耳（`#D4A55F` 内耳 `#F0CE9B`）。眼为 2×2px 坚定方眼（outline），口鼻 3×3px 浅米 `#F0CE9B` + 鼻点
- **衣服**：紫 `#9B7EC4` 西装，肩部加宽 1px（垫肩感），领口白色感 `#C9B4E0` 衬衫三角

### ENTP 辩论家 × 狐狸（主色 #C9B4E0）
- **气质**：机灵、狡黠、坏笑
- **头部像素设计**：橘 `#D4A55F`。**尖耳**：左右各 3×4px 高挑三角耳（比猫耳高 1px），耳尖 1px 深棕 `#6B4A1F`。**尖吻**：面部下方中央向前突出 2×3px 的吻部，吻端 1px 鼻点（outline），吻侧浅米 `#F0CE9B` 过渡。**吊梢眼**：2×2px 眼，外眼角上挑 1px——狐狸的狡黠靠这 1px 上挑

## 5. 风格统一自检清单（每只产出后逐条过）

1. 骨架坐标与 §0 完全一致（只换头 + 衣服配色）
2. 外轮廓 1px `#2B2320`，无断边、无双线
3. 光源左上：左/上浅、右/下深
4. 全部颜色 ∈ 16 色板 ∪ {outline}，alpha ∈ {0, 255}
5. 把 16 只并排放：头部轮廓两两不重复（靠剪影就能猜出 8 成动物）
6. 衣服主色 = 人格专属主色，不看头也能认出是哪个族
